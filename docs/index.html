How it works

Every step has one of three owners

Script

One right answer. Free, instant, the same every time.

  • read the issue
  • lint tasks
  • run tests
  • check evidence

Agent

Needs judgment. Follows a skill written for that one job.

  • write requirements
  • design
  • build a task
  • review

You

A decision about your product. The factory waits.

  • approve requirements
  • approve screens
  • merge
One item, start to finish

Proof, not promises

Nothing is done until a script agrees

Maker builds the taskUsing the skill the task names. It may not run the gate.
A separate checker runs the gateFresh context. Writes the evidence sheet.
A script re-runs the checks itselfMismatch or missing evidence sends the work back.
You review evidence, not logsEach gate leaves one file you can read in a minute.

Create yours

Three commands to a running factory

01

Start from a sample

Point it at your repository.

python3 factory/flow.py init shop \
  --sample backend-api --repo ~/code/shop
02

Make it yours

Set the source, your rules, and your test command. Move the human steps where you want them.

python3 factory/flow.py --target shop show
python3 factory/flow.py --target shop validate
03

Run one issue

It stops at your first human step.

python3 factory/flow.py --target shop \
  start --issue 42
python3 factory/flow.py --target shop run
