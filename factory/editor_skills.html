Maker skills

These are the skills a task can name. When the tasks are written, each task is given the one skill that fits the files it touches, and a script rejects a task that names the wrong one. Say what each skill is for.

Stage skills

The skill each stage on the pipeline follows, including the checker that verifies the maker's work in a separate session.

Add a skill

A skill is a short document that says how to do one job. Bring one in, or write your own.
